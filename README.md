# All Set Consulting

Marketing one-pager for **All Set Consulting** — CRM & ERP implementation specialists.

> Set up. Switched on. All set.

## Stack

- **Next.js 15** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS v4** for styling
- **Motion** (framer-motion) for scroll reveals + transitions
- Custom **HTML5 Canvas** particle-network for the hero background

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub and import the repo on [Vercel](https://vercel.com/new) — zero config needed.
